<h2 id="english">🇺🇸 English Version</h2>

I am a Software Developer and Architect based in Argentina. I design modular, high-performance software systems—which I refer to as **Blueprints**—tailored to optimize conversions, automate operations with private artificial intelligence, and protect user data via local-first design architectures.

I build software that balances production reliability with user privacy, focusing on robust data structures, edge architectures, and smooth user experiences.

*2025–present*

* Structure behavior-governed AI integrations using FastAPI and Ollama for secure, on-premise execution with zero data leakage.

**Current focus:** Headless e-commerce performance, local LLM integrations (RAG), and offline-first/local-first data syncing.

---

### Projects & open source

*   **[NubeBoost](https://evecchio.github.io/FVision-Builders/)** — Checkout and load-speed optimization framework for Tiendanube. Re-engineers visual hierarchy and user flows to reduce cart abandonment by up to 35%.
*   **[CoreStore Headless](https://evecchio.github.io/FVision-Builders/)** — Ultra-fast headless e-commerce frontend built with **Next.js 15**, **React 19**, and **TypeScript**. Focuses on offline-persistent carts, immediate loading, and SEO optimization.
*   **[SpendGuard Mobile](https://evecchio.github.io/FVision-Builders/)** — A 100% private expense tracker written in **Kotlin** and **Jetpack Compose**. Listens to local bank notifications in the background, extracts transaction details via Regex, and stores data in a local encrypted **Room DB**.
*   **[SafeRAG Local](https://evecchio.github.io/FVision-Builders/)** — A fully offline corporate assistant. Combines **FastAPI**, **Ollama**, and **Chroma DB** to parse documents and answer queries locally without network requests.
*   **[DropLand](https://github.com/Evecchio/DropLand)** — Local network downloader. Written in **Python** and **Tkinter**, it runs a lightweight web server that allows users to manage, convert, and trigger media downloads from any mobile device on the network.
*   **[DRDV Framework](https://evecchio.github.io/FVision-Builders/)** — A YAML-based validation runtime for multi-agent LLM systems. Enforces strict behavior contracts through the *Design-Review-Decide-Validate* lifecycle.
